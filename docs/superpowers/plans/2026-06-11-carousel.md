# Claude Code 핸드오프 — Featured 캐러셀 모바일 오버플로 수정

> **대상 컴포넌트:** `src/components/FeaturedCarousel/`
> **스택:** Next.js + React + TypeScript + **Vanilla Extract** (`@vanilla-extract/css`)
> **작업 성격:** 버그 수정(반응형). 마크업/로직 변경 없음 — **`styles.css.ts`만 수정**한다.

---

## 1. 문제 (What's broken)

좁은 모바일 뷰포트에서 Featured 캐러셀의 슬라이드 콘텐츠(카테고리·제목·발췌·메타)가 **상자 밖으로 넘쳐 잘려 보인다.**

- 넓은 폭: 제목/발췌가 1~2줄이라 콘텐츠가 박스 안에 다 들어옴 → 정상.
- 좁은 폭(≈320~414px): 가로 폭이 줄며 텍스트가 위로 더 쌓임 → 콘텐츠가 박스 상단을 넘어가고, 박스의 `overflow: hidden`에 잘림.

### 근본 원인 (Root cause)

오버레이 캐러셀은 모바일에서 **고정 `aspect-ratio`(16/9)** 로 높이가 가로폭에 고정돼 있다. 한편 슬라이드 텍스트 블록(`.cslide__inner` 상당)은 `position: absolute`로 **박스 하단에 핀** 되어 있어, 텍스트가 길어지면 위쪽으로 자라며 고정 높이 박스의 위 경계를 넘어 잘린다.

```
[고정 높이 박스]  ← aspect-ratio로 높이 잠김
┌──────────────┐ ← 콘텐츠가 이 위 경계를 넘어 잘림 ✂
│  제목 줄2 ✂   │
│  제목 줄1     │
│  발췌…        │  ← inner는 bottom:0 에 핀, 위로 성장
└── 메타 ───────┘
```

### 해결 전략 (Fix)

좁은 뷰포트(`≤720px`)의 **overlay 변형**에서만 고정 `aspect-ratio`를 버리고, **박스 높이를 활성 슬라이드 콘텐츠에 맞춰 자라게** 한다. 즉:

1. `root`(`.carousel`): `aspect-ratio: auto`
2. `track`(`.carousel__track`): `position: absolute` → `relative`, `height: auto`, `align-items: stretch` (자식이 높이를 만들도록 흐름에 복귀)
3. `slide`(`.cslide`): `height: auto` + `min-height: clamp(232px, 62vw, 340px)`(짧을 때 이미지 밴드 유지) + `flex column` + `justify-content: flex-end`(하단 정렬 유지)
4. `slideInner`(`.cslide__inner`): `position: absolute` → `relative`, `overflow: visible`, 패딩 축소 → **흐름에 들어와 슬라이드 높이를 만든다 → 더 이상 잘릴 수 없다.**
5. 정리: dots를 하단 중앙으로 옮겨 줄바꿈된 메타 라인과 겹치지 않게, 화살표는 모바일 숨김 유지.

> `split` 변형은 건드리지 않는다(별도 `aspect-ratio: 4/5` 유지). 모바일 분기만 추가/수정한다.

## 2. 정확한 코드 (Source of truth)

이 핸드오프에는 **수정 완료된 `styles.css.ts` 전체 파일**이 함께 첨부돼 있다:

```
codebase-patch/FeaturedCarousel.styles.css.ts
```

→ 이 파일을 `src/components/FeaturedCarousel/styles.css.ts` 에 **그대로 덮어쓰면 된다.** `FeaturedCarousel.tsx`는 변경 불필요.

수정의 핵심은 Vanilla Extract `globalStyle()`로 `html[data-carousel="overlay"]` 스코프 하에 모바일 분기를 추가하는 것이다(아래는 발췌 — 전체는 첨부 파일 참조):

```ts
// 박스: 모바일 overlay에서 고정 비율 해제 → 콘텐츠 높이로 성장
globalStyle(`html[data-carousel="overlay"] .${root}`, {
  '@media': { '(max-width: 720px)': { aspectRatio: 'auto' } },
});

// 트랙: 절대 배치 해제, 자식 높이를 따라가도록
globalStyle(`html[data-carousel="overlay"] .${track}`, {
  '@media': { '(max-width: 720px)': {
    position: 'relative', height: 'auto', alignItems: 'stretch',
  } },
});

// 슬라이드: 콘텐츠 높이 + 최소 높이(이미지 밴드) + 하단 정렬 컬럼
globalStyle(`html[data-carousel="overlay"] .${slide}`, {
  '@media': { '(max-width: 720px)': {
    height: 'auto',
    minHeight: 'clamp(232px, 62vw, 340px)',
    display: 'flex', flexDirection: 'column', justifyContent: 'flex-end',
  } },
});

// 텍스트 블록: 흐름에 복귀 → 더 이상 잘리지 않음
// (slideInner 의 style() @media 분기로)
'@media': { '(max-width: 720px)': {
  position: 'relative', maxWidth: '100%', width: '100%',
  overflow: 'visible', padding: '22px 20px 46px',
} },

// dots: 하단 중앙으로 — 줄바꿈된 메타와 충돌 방지
'@media': { '(max-width: 720px)': {
  left: '50%', right: 'auto', transform: 'translateX(-50%)', bottom: 14,
} },
```

> ⚠️ Vanilla Extract 주의: `&`(셀렉터 자기참조)는 `style({ selectors })` 안에서만 동작한다. `html[data-carousel="overlay"] .${root}` 처럼 **부모 데이터 속성 + 생성 클래스** 조합은 `globalStyle()`로 써야 한다(첨부 파일이 이미 그 형태). 클래스명을 문자열로 직접 쓰지 말고 반드시 `.${root}` 템플릿 보간을 사용한다.

## 3. 동작/회귀 기준 (Acceptance criteria)

수정 후 다음을 만족해야 한다.

- [ ] **320 / 360 / 414px** 폭에서 활성 슬라이드의 카테고리·제목·발췌·메타가 **모두** 캐러셀 박스 안에 보인다(상/하단 잘림 0).
- [ ] 박스 높이가 활성 슬라이드 콘텐츠에 맞춰 자란다(고정 16/9 아님). 콘텐츠가 짧아도 `min-height`로 이미지 밴드가 유지된다.
- [ ] dots가 하단 중앙에 있고 줄바꿈된 메타 라인과 겹치지 않는다. 화살표는 모바일에서 숨김.
- [ ] **데스크톱(>720px) overlay 레이아웃은 변화 없음** — 기존 `aspect-ratio: 16/7` 유지, 텍스트는 여전히 좌하단 오버레이.
- [ ] **split 변형**(`data-carousel="split"`)은 영향 없음.
- [ ] 슬라이드 전환(translateX) 애니메이션·자동재생·점프 동작 정상.
- [ ] 콘솔 에러 0, 타입 에러 0(`tsc`/빌드 통과).

### 검증 팁

DevTools 디바이스 모드 320px에서 활성 `.cslide__inner` 의 `getBoundingClientRect()` 상/하단이 `.carousel` 박스 경계 안에 있는지 확인:

```js
const box = document.querySelector('.carousel').getBoundingClientRect();
const inner = document.querySelector('.cslide:not([aria-hidden="true"]) .cslide__inner')
  .getBoundingClientRect();
console.log(inner.top >= box.top - 0.5 && inner.bottom <= box.bottom + 0.5); // → true
```

(생성 클래스명은 해시가 붙으므로 실제 셀렉터는 빌드 산출물 기준으로 맞춘다. 위는 디버그 attr 예시.)
